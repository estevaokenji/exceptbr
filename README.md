# exce.ptBR

💬 Um traceback Python traduzido para português brasileiro. ☕

O exceptbr substitui o traceback padrão do Python por uma versão mais amigável, mostrando:
- erro traduzido;
- arquivo e linha do problema;
- trecho do código;
- destaque da linha com erro.

O visual renovado é intuitivo para facilitar sua compreensão do erro.

## Instalação

1. Baixe os arquivos do exceptbr
2. Abra o terminal
3. Use:
```bash
cd [local-da-pasta]
pip install .
```
